Política de Privacidade

Atualizada em 8 de novembro de 2026

Quem usa

O Jarvis é um aplicativo de uso privado. Só o dono da conta do Google conectada usa o aplicativo, para gerenciar o próprio canal do YouTube.

Dados acessados

Com a permissão do dono, o Jarvis acessa pela API do YouTube: o nome e os números do canal, e o envio de vídeos, títulos, descrições, miniaturas e agendamentos.

Como os dados são usados

Os dados servem só para publicar e organizar o conteúdo do próprio canal. Não são vendidos, compartilhados nem usados para publicidade.

Onde ficam

Os tokens de acesso ficam criptografados no computador do dono. Nenhum dado do Google é enviado a terceiros.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O Jarvis também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.
